I take web apps **from source code to a live server**: containerize them, automate the build and deploy with CI/CD, put them behind Nginx and Cloudflare, and run them on Kubernetes with GitOps. Everything listed here is practiced on real projects running on my own servers. Currently going deep into **DevOps**, with **Backend** and **Frontend** next on the roadmap.

---

## 💼 Hands-on work

| Project | What I did | Result |
|---|---|---|
| **DevForge** — AI CV analysis platform | Dockerized the app, set up Nginx reverse proxy with domain/subdomain, configured Cloudflare (cache rules, WAF, rate limiting, IP allowlist), built CI/CD with GitHub Actions, deployed to Kubernetes with ArgoCD, added monitoring | Live at [devforge.io.vn](https://devforge.io.vn) |
| **VOLTA Ride** — EV rental website | Wrote Dockerfile + `docker-compose.yml` for a React + Spring Boot + PostgreSQL stack and deployed it on a personal Ubuntu server | Full stack running in containers |
| **Team mini project** | DevOps role in a team of developers: Git branching workflow, Docker Compose, CI/CD pipeline | Automated build & deploy for the team |
| **Ubuntu Server labs** | Server survey & hardening, role-based Linux permissions, port security, networking | Secured, reproducible server setup |
